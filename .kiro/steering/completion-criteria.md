# 完了条件ガイドライン

## 基本原則

**すべての作業は以下の条件を満たして初めて完了とする**

## 完了条件（必須）

作業完了前に、必ず以下の3つをすべて実行すること：

### 1. テストが成功

```bash
npm test
```

**確認事項**:
- すべてのテストがパス
- 新規追加したテストも含む
- 特定のテストファイルだけでなく、**全テストスイート**を実行

### 2. Lintが成功

```bash
npm run lint
```

**確認事項**:
- Lintエラーがゼロ
- 警告は許容範囲内（`--max-warnings` で設定された値以下）

### 3. ビルドが成功

```bash
npm run build
```

**確認事項**:
- TypeScriptのコンパイルエラーがゼロ
- ビルド成果物が正常に生成される

## 完了の定義

以下の3つが**すべて**揃って初めて「完了」：

- ✅ テスト成功（全テストスイート）
- ✅ Lint成功（エラーゼロ）
- ✅ ビルド成功（コンパイルエラーゼロ）

## 理由

- **テスト失敗** = 機能が壊れている → デプロイ不可
- **Lint失敗** = コード品質基準を満たしていない → 保守性低下
- **ビルド失敗** = デプロイできない → リリース不可

## Git コミット・プッシュ前のチェックリスト

- [ ] `npm test` を実行し、全テストが成功した
- [ ] `npm run lint` を実行し、エラーがゼロであることを確認した
- [ ] `npm run build` を実行し、ビルドが成功した
- [ ] `git status` で変更内容を確認した
- [ ] `git diff --staged` でステージング内容を確認した
- [ ] 個別ファイルを `git add` した（`git add .` は使用していない）

## CI/CD との関係

ローカルで上記3つが成功していれば、CI/CDでも成功するはず。

**CI/CDで失敗する場合**:
- ローカルで完了条件を満たしていない
- 環境差異がある（Node.jsバージョン等）

## 例外

以下の場合のみ、一部の条件をスキップ可能：

1. **ドキュメントのみの変更**: テスト・ビルドはスキップ可（Lintは実行）
2. **緊急の本番障害**: 即座の対応が必要（後日必ず完了条件を満たす）
