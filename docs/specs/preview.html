DynamoDB Client API (1.3.34)

Download OpenAPI specification:

URL: https://github.com/exabugs/dynamodb-client License: MIT

MongoDB-like API for DynamoDB with shadow record support for efficient querying.

This API provides a familiar MongoDB-style interface for interacting with DynamoDB, supporting 10 operations compatible with react-admin.

Supported Operations:

  • find: Query documents with filters
  • findOne: Get a single document
  • findMany: Get multiple documents by IDs
  • findManyReference: Get documents by reference field
  • insertOne: Create a single document
  • insertMany: Create multiple documents
  • updateOne: Update a single document
  • updateMany: Update multiple documents
  • deleteOne: Delete a single document
  • deleteMany: Delete multiple documents
